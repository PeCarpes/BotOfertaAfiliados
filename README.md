# Bot de Ofertas - Afiliados (Laura)

Este é um script de automação web construído em Python utilizando Selenium. O objetivo inicial é buscar, filtrar e extrair ofertas do Mercado Livre para facilitar a divulgação de links de afiliados.

## 🚀 Tecnologias
* Python 3
* Selenium (Web Scraping e Automação)

## ⚙️ Como configurar e rodar o projeto

### Pré-requisitos
Certifique-se de ter o Python instalado na sua máquina e o navegador Google Chrome (ou Chromium).

### Instalação no Windows
1. Clone o repositório:
   `git clone https://github.com/SEU_USUARIO/BotAfiliadoLaura.git`
2. Entre na pasta do projeto:
   `cd BotAfiliadoLaura`
3. Crie o ambiente virtual:
   `python -m venv venv`
4. Ative o ambiente virtual:
   `.\venv\Scripts\activate`
5. Instale as dependências:
   `pip install -r requirements.txt`

### Instalação no Linux (Ubuntu)
1. Clone o repositório:
   `git clone https://github.com/SEU_USUARIO/BotAfiliadoLaura.git`
2. Entre na pasta do projeto:
   `cd BotAfiliadoLaura`
3. Crie o ambiente virtual:
   `python3 -m venv venv`
4. Ative o ambiente virtual:
   `source venv/bin/activate`
5. Instale as dependências:
   `pip install -r requirements.txt`

## ▶️ Como executar
Com o ambiente virtual ativado, rode o comando:
`python bot.py`
